## 2. 年级判定结果（本轮核心交付）

### 2.1 判定口径

**`grade`** = 官方教材选用/征订目录标注的年级，取「最早被正常讲授的年级」。
之所以取**最早**年级，是因为检索侧按年级做的是**软加权而非硬过滤** ——
若取较晚年级，学生提前自学时该册书会被系统性降权。

**`grade_span`** = 兼顾各校教学进度差异的适用区间，供软加权使用。

年级编码与 GUI 对齐：`10` = 高一，`11` = 高二，`12` = 高三。

### 4.4 忠实度校验的效果与**局限（重要）**

对「库外问题」（"请介绍量子色动力学中的渐近自由现象…"）的处理：

| 阶段 | 行为 |
|------|------|
| 优化前 | 无任何校验（`validate_grounding` 是死代码），直接输出模型编造的内容 |
| 优化后 · 第一版（单汉字重叠） | 未能拦住，模型编造了 QCD 内容 |
| 优化后 · 第二版（中文二元组） | 覆盖度 7.7% → 判为无据，模型输出"材料中未找到相关信息" |

**但标定发现该指标对中文的区分力很弱**，实测数据：

| 问题类型 | 内容覆盖度 | 应判为有据？ |
|---------|:---------:|:-----------:|
| 《乡土中国》核心观点 | 79.3% | 是 |
| 向心力（概念题） | 33.0% | 是 |
| 导数的几何意义 | **17.3%** | 是 |
| 量子色动力学（库外） | 12.3% | **否** |

有据答案的覆盖度可以低到 17%，与库外问题的 12% 几乎重叠 —— 中文模型会大量改写、且公式与符号不产生二元组。**因此最终改为分级处理**：

- **硬信号**：模型自认无据（"材料中未找到"/"根据常识"等）→ 追加免责提示 + 置信度上限 0.4；
- **软信号**：内容覆盖度低于 0.15 → 仅对置信度打 0.7 折扣，**不加横幅**（避免对改写幅度大的有据答案误报）。

> 本轮最值得记录的一条工程判断：**不要把弱指标当强判据**。
> 一个动辄误报"依据不足"的横幅，比没有横幅更伤害用户信任。

## 6. 本轮发现但**未处理**的事项（留给 P1）

1. **无评测集**：本轮改动效果只能靠冒烟与人工抽检确认，**尚无量化基线** —— 这是 P1 的第一优先项。
2. **PDF 字形乱码**：抽样 52 万字符中有 **0.16%** 落在中英教材不应出现的字符区（私用区 PUA、卡纳达文、泰文等），
   集中在数学册（选必一 1.18%、必修二 1.01%），系 PDF 字体未映射到 Unicode 所致。
   会产生类似 `㱎಄⮱Ѻ㒛` 的乱码块，建议在 P1 内容清洗阶段做块级噪声过滤。
3. **无 BM25 关键词召回**：术语型问题（"万有引力常量"）仍依赖稠密向量，P1 补混合检索。
4. **无父子索引 / 标题层级切分**：当前仍是 512 字符定长块（仅修好了断点位置），
   导致 512 字符块在 1200 token 预算下只能放进 2–3 块。
5. **各册书未按章节拆分元数据**：`chapter` / `section` / `page` / `content_type` 字段已预留但暂填默认值，待 PDF 结构解析。
6. **`ingest_manifest` 路径未接入教材目录**：离线内容包仍使用包内自带的 metadata。
7. **`English Grammar` / `Social Studies` 无教材**：这两个学科在 GUI 中存在但库里没有对应教材，
   路由会正确返回空集合并触发拒答（而非过去的静默串答案）。若需要，需补充英语、政史地教材。
8. **GUI 学科列表由 `content_manager` 内容文件驱动**：新增的「语文」显示名已就位，
   但若内容目录下没有语文内容文件，学科入口需要另行补充。
